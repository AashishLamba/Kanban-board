### Kanban Board - Vanilla JavaScript

A simple Kanban Task Management application built using HTML, CSS, and Vanilla JavaScript.  
It helps users manage tasks across different stages like To Do, In Progress, and Done.

---

##  Features
-  Add new tasks using modal
-  Drag and drop tasks between columns
-  Delete tasks
-  Data persistence using LocalStorage
-  Dynamic task count per column
-  Dark themed responsive UI

---

##  Tech Stack
- HTML5
- CSS3 (Flexbox, Variables)
- JavaScript (Vanilla JS)
